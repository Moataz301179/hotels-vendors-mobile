// Expo Dev Commands

## Running iOS Simulator
Run one of these commands from the project root:

```bash
# Option 1: Start Expo dev server and scan QR code with Expo Go
npx expo start

# Option 2: Run directly on connected iOS simulator
npx expo run:ios

# Option 3: Use with existing simulator
npx expo start --device
```

## Troubleshooting
If app doesn't show:
1. Make sure iOS Simulator is running (open Simulator.app)
2. Run: npx expo run:ios
3. Or: npx expo start, then click "Run on iOS simulator" in the browser interface
